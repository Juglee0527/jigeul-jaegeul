# 🎮 지긁재긁 (Jigeul-Jaegeul)

> **긁히면 진다.**

기본 10분 또는 퀵 5분 동안 몰려오는 **스트레스와 밈**을 뚫고 보스를 쓰러뜨리는 웹 로그라이크 생존 게임.

---

## 📖 소개

**지긁재긁**은 누구나 한 번쯤 겪어본 "긁히는 순간"들을 게임으로 만든 웹 게임입니다.

"ㅋㅋ"

"5분만."

"회의 하나만."

"배송 지연"

"리뷰 ★1"

"품절"

평범한 말들이 몬스터가 되어 몰려옵니다.

당신은 끝까지 버틸 수 있을까요?

---

## 🎯 게임 목표

* 기본 모드에서는 3분·6분·10분 보스, 퀵 모드에서는 2분·5분 보스를 쓰러뜨리세요.
* 레벨업으로 일반·희귀·에픽·전설 능력을 최대 3단계까지 성장시키세요.
* 보스가 떨어뜨린 보물상자에서 전설 능력을 획득하세요.
* 친구와 최고 기록을 경쟁하세요.

> **긁히면 지고, 버티면 승리합니다.**

---

## ⚔️ 게임 특징

### 🧠 자동 공격

공격은 자동으로 이루어집니다.

플레이어는 이동과 생존에만 집중하면 됩니다.

### 🎵 네온 신스 사운드

첫 입력부터 절차형 BGM이 재생되며 메뉴, 전투, 일시정지, 결과 화면에 따라 분위기가 달라집니다. 공격·타격·처치·피격·경험치·레벨업에도 전용 효과음이 적용됩니다.

---

### 📈 로그라이크 성장

레벨업마다 세 장의 능력 중 하나를 선택합니다. 총 33종의 능력은 일반·희귀·에픽·전설의 네 등급이며, 모든 능력은 3레벨이 최대입니다. 마지막 강화 카드는 `LV.2 → MAX`로 표시되고 최대 레벨이 된 능력은 더 이상 후보에 나오지 않습니다.

등급은 생존 시간에 따라 일반(시작), 희귀(30초), 에픽(60초), 전설(90초) 순으로 해금됩니다.

단순 능력치 강화뿐 아니라 관통·치명타·후방/측면 사격·처치 폭발·연쇄 공격·주기적 광역탄·처형·보호막·부활 같은 빌드 효과가 실제 전투에 적용됩니다. `ESC` 일시정지 화면에서는 획득한 능력과 레벨, 초당 발사 수를 포함한 전체 전투 능력치를 확인할 수 있습니다.

피해 감소는 능력 단계당 10%씩 증가하며 한 번의 피해를 최대 90%까지만 줄입니다. 자동 회복은 마지막 피격 1초 후 시작되며 최대 멘탈의 초당 10%를 상한으로 적용합니다.

예시

* ☕ 커피
* 🛡 강철 멘탈
* 🔥 팩트 폭격
* 📦 무료배송
* 😐 읽씹
* 💥 지긁재긁

매 판마다 다른 빌드를 만들 수 있습니다.

### 👾 개성 있는 적

평범한 몬스터가 아닙니다.

* "ㅋㅋ"
* "ㅇㅋ"
* "5분만"
* "회의 추가"
* "배송 지연"
* "쿠폰 종료"
* "품절"
* "재입고 미정"

3분에는 대시형, 6분에는 순간이동형, 10분에는 영역·회전 탄막형 최종 보스가 등장합니다. 보스전 중에는 게임 시간이 멈추며 일반 적 지원군은 등장하지 않습니다.

일반 적도 모두 플레이어만 쫓지 않습니다. 1분 이후부터 등장하는 파란색 배회형 두글자 적은 플레이어를 무시하고 화면을 돌아다녀 전장의 흐름을 흔듭니다. 적 무리는 외형이 절반가량 겹칠 수 있지만 완전히 한 점에 포개지지는 않습니다.

보스마다 전용 외형과 이동 방식, 공격 예고가 있습니다. 직선 대시, 출발·도착 순간이동 탄막, 회전 결재선과 마감 구역을 구분해 피해야 합니다. 전투가 길어진다는 이유로 공격 주기가 계속 빨라지지는 않습니다.

### 🏆 점수 경쟁

* 살아남은 매초마다 10점
* 적 멘트 글자 수가 높을수록 더 큰 처치 점수
* 3분·6분·10분 보스는 단계별 고레벨 처치 점수
* 유효 피격마다 100점 감점(최소 0점)

친구들과 기록을 경쟁해 보세요.

## 🚀 플레이

[GitHub Pages에서 지긁재긁 플레이하기](https://juglee0527.github.io/jigeul-jaegeul/)

로컬에서는 다음 명령으로 실행할 수 있습니다.

```bash
npm install
npm run dev
```

프로덕션 빌드와 미리보기:

```bash
npm run build
npm run preview
```

Node.js 22 이상과 npm을 권장합니다.

### 조작 방법

- `WASD` 또는 방향키: 이동
- 공격: 가장 가까운 적을 향해 자동 발사
- 메인 메뉴: `↑`·`↓`로 항목 이동, `Enter`로 선택
- 난이도: 메인 메뉴에서 `←`·`→` 또는 마우스로 쉬움·보통·어려움 선택
- 일시정지: `ESC`, 메뉴는 `↑`·`↓`로 이동하고 `Enter`로 선택
- 능력 선택: `←`·`→`로 이동하고 `Enter`로 선택
- `Enter`: 결과 화면에서 다시 시작

현재 기본 10분·퀵 5분 게임 루프, 단계별 보스전, 중간 보스 전설 보물상자, 추적·배회·도망·돌진·공전형 적, 4등급 성장, 점수와 브라우저 최고 기록 저장까지 구현되어 있습니다.

난이도는 현재 밸런스를 `보통`으로 사용합니다. 쉬움은 1~4레벨, 보통은 1~5레벨, 어려움은 2~6레벨 일반 적이 등장합니다. `쉬움`은 일반 적과 보스의 체력·이동속도·접촉 피해·탄막 피해가 0.5배, `어려움`은 1.5배입니다.

메뉴의 **오늘의 도전**에서는 로컬 날짜를 시드로 사용합니다. 같은 날짜에는 적 등장과 능력 후보 순서가 재현되며 날짜별 최고 점수가 저장됩니다.
